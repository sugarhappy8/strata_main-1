01 / Choose your device

INSTALL IN FOUR STEPS.

STRATA is a web app, so there is no App Store download. Your browser adds it directly to your Home Screen or apps list.

iPhone / iPadAndroidChromeEdge

01 / Apple mobile

Recommended for this device

IPHONE OR IPAD

Use Safari—not an in-app browser.

  1. Open STRATA in Safari.
  2. Tap the Share button.
  3. Scroll down and tap Add to Home Screen.
  4. Turn on Open as Web App, then tap Add.

Missing the option? At the bottom of the Share menu, tap Edit Actions and add it.

02 / Android mobile

Recommended for this device

ANDROID

Chrome gives the most reliable install option.

  1. Open STRATA in Chrome.
  2. Tap the three-dot menu by the address bar.
  3. Tap Install app or Add to Home screen.
  4. Confirm Install, then open STRATA from its new icon.

The wording varies slightly between Android and Chrome versions.

03 / Computer

Recommended for this device

GOOGLE CHROME

Works on Windows, macOS, ChromeOS, and Linux.

  1. Open STRATA in Chrome.
  2. Select the Install icon in the address bar if it appears.
  3. Otherwise open the three-dot menu and find Install page as app.
  4. Select Install.

Chrome may place the command inside Cast, save and share.

04 / Computer

Recommended for this device

MICROSOFT EDGE

Use Edge's built-in Apps menu.

  1. Open STRATA in Edge.
  2. Open Settings and more (…).
  3. Choose Apps, then Install this site as an app.
  4. Select Install.

You can manage the installed app later from Edge's Apps menu.

02 / Quick fixes

CAN’T SEE INSTALL?

  • Let STRATA finish loading, then refresh the page once.
  • Use Safari on iPhone or iPad, or Chrome on Android.
  • Leave Private or Incognito browsing.
  • Check whether STRATA is already on your Home Screen or in your apps.
  • You can always bookmark STRATA and keep using it in the browser.

Your account stays the same. Installing does not create another profile or move your data. Sign in with the same account on every device. Account syncing and saved changes still need an internet connection.
